# Cablueie（カブリエ）公開サイト

GitHub Pages にそのまま置けるファイル一式です。

- `index.html` … トップ（料金・空き状況・申し込み）
- `pay/` … お支払いページ（メールのリンクから開く）
- `terms/` … 貸渡約款
- `legal/` … 特定商取引法に基づく表記
- `config.js` … 裏方（Googleのウェブアプリ）のURL。デプロイIDが変わったときだけ書き換えます
- 独自ドメインは GitHub の「Settings → Pages → Custom domain」で設定します
- `robots.txt` / `sitemap.xml` … 検索エンジン向け

料金・連絡先・空き状況・許可番号は、Googleの「Cablueie 予約管理」スプレッドシートから自動で表示されます。
